01 / FEATURES

只解决班牌上的真实问题。

F-01
Bar — 把导航栏叫回来

系统自动隐藏导航栏时，一键收起键盘并尝试唤回 Back / Home / Recent。ROM 不配合也不崩溃。

F-02
HOME — 直接回桌面

消息程序霸占前台时，一键回到 Android 桌面。不强杀、不驻留任何应用。

F-03
横屏三栏布局

方案与数字在左、主输入在中、编辑键在右。按键尺寸与间距为触控重算，竖屏自动回退原布局。

F-04
全拼 · 双拼 · 9键 · 手写

四套方案常驻切换，当前方案高亮。内核沿用成熟实现，雾凇词库持续维护。

F-05
公共设备守则

无账号、无广告、无行为统计、无内容上传。每日自动清理自学习词库，所有人体验一致、可预测。

02 / PRINCIPLE

一句话原则。

能用，大于稳定，大于体验，大于美观，大于完美。
班牌挂在教室门口，谁都会去碰一下——所以它必须结实、必须离线、必须让第一千次使用和第一次一样可预测。
